# 三国志·天下争锋 —— 首版玩法说明

> 大白话说明：怎么玩、地图什么样、仗怎么打。  
> 竖屏 **1080×1920**。  
> 玩法对齐光荣安卓 [《三國志２》](https://play.google.com/store/apps/details?id=jp.co.koeitecmo.rtk2&hl=zh)（手机《三国志·TOUCH》续作那一支）。

---

## 1. 一句话

你当一方君主。天下由许多**城**连成网。每个月：

1. 在己方城做内政（开发、商业、治水、巡查、征兵、训练）；  
2. 在己方城之间调武将、粮、钱、兵；  
3. 出征邻城，进入**格子战棋**打完再回大地图；  
4. 招人、外交。

打到只剩你一家，就赢了。

| 模块 | 内容 |
|------|------|
| 开局 | 选剧本 + 选君主 |

实现可以分步加深（计略种类、联军、外交条目等），但主循环就是上表这些。

## 3. 地图

### 3.1 结构

- 一张天下大势图。  
- 基本单位是**城**，城与城有路（邻接）。  
- 只能沿路走到邻城。

点城 = 开城菜单；出征 = 沿线走过去打。

首版城数量建议先 **30～50 座** 跑通，邻接关系做对后再加密。

### 3.2 一座城记什么

与现有 `City` 对齐，并按官方补齐：

- 归属势力  
- 人口  
- 金钱、粮草  
- 兵力  
- 开发/农业、商业  
- 治水（抗灾）  
- 训练度（与征兵分开）  
- 民忠、治安  
- 太守  
- 邻城列表  

### 3.3 地图操作

- 己方城 → 内政、人事、出征、调配  
- 敌方城 → 看情报、准备进攻  
- 行军中部队 → 续进、撤退、开战  

竖屏布局建议：**上半地图，下半当前城/部队命令**。

## 4. 时间：一个月一轮

- **年 + 月**（工程已有 `Turn`、四季）。  
- 下完本月命令 → 结束回合 → 结算 → AI → 下个月。

每月大致顺序：

1. 执行已下命令（建设、行军到位等）  
2. 城池月结：产钱产粮、养兵吃粮、民忠治安变化  
3. 灾害（与治水相关）  
4. 武将状态（伤愈、忠诚；年龄可按年涨）  
5. 少量随机事件  
6. AI 行动  
7. 胜负检查  
8. 月份 +1  

武将本月办过大事标记「已行动」（已有 `actionUsed`）。

## 5. 势力与武将

### 5.1 势力

- 有君主、颜色、城、将。  
- 玩家一家，其余 AI。  
- 没有城 → 灭亡。

### 5.2 五维

| 属性 | 主要用处 |
|------|----------|
| 武力 | 单挑、近战 |
| 智力 | 计略、部分内政 |
| 统率 | 带兵、部队强度 |
| 政治 | 内政效率 |
| 魅力 | 登用、安抚、外交 |

另有：忠诚、年龄、所在城、状态（空闲 / 太守 / 出征 / 负伤）。

### 5.3 武将来源

- 剧本开局就位  
- 寻访 / 登用在野  
- 俘虏劝降  
- 赏赐维持忠诚  

图鉴目录作素材库，开局按剧本落到各城。

## 6. 内政命令

城菜单应对齐：

1. **开发** — 抬产出基础  
2. **商业** — 抬金钱收入  
3. **治水** — 抗灾、护农业  
4. **巡查** — 抬治安  
5. **征兵** — 钱粮换兵  
6. **训练** — 抬训练度  
7. **调配** — 己方城之间调将、兵、金、粮  
8. **登用 / 寻访** — 招人  
9. **任命太守**  

流程：选武将 → 消耗金钱或行动 → 按属性出结果。

---

## 7. 行军与战斗

### 7.1 大地图出征

1. 己方城选将、带兵、带粮  
2. 朝邻城前进（可经己方城中转）  
3. 抵达敌城或遭遇敌军 → 进入战场  

### 7.2 战场

对齐官方重点：格子战棋、计略、单挑、战斗压迫感。

首版目标：

- 格子战棋（方格或六角，实现前定一种）  
- 每队一个武将带一队兵  
- 回合内：移动、攻击  
- 计略：至少火计一类（与智力相关）  
- 单挑：可比武力，影响士气或伤势  
- 守城有加成；歼敌或破城后回大地图占领  

落地可以分两步：

1. 能进战场、能移动攻击、能分胜负并占城  
2. 再叠单挑、更多计略、联军等  

### 7.3 占领之后

- 城易主  
- 敌将：俘虏或逃走  
- 金粮兵按规则接收  
- 民忠短期下降，需安抚

## 8. 外交

- 同盟  
- 停战  
- 劝降（条件苛刻）  
- 随后可加：要钱、要粮、离间等

## 11. 胜负

- **胜**：只剩玩家一个势力  
- **负**：玩家没有城  

---

## 12. 主循环

```
主菜单 → 选剧本 → 选君主 → 大地图
     ↓
  每月：内政 / 人事 / 出征 / 外交
     → 结束回合 → 事件与 AI
     → 遇敌进战场 → 打完回大地图
     ↓
  统一或灭亡 → 回主菜单（完整 GameState 存档）
```

---

## 13. 和工程怎么接

**已有：** 主菜单；`GameState` / `City` / `Faction` / `Officer` / `Turn`；武将目录。

**建议顺序：**

1. 城池 + 邻接 + 剧本初始布局  
2. 战略地图屏  
3. 月结 + 结束回合  
4. 内政命令  
5. 行军  
6. 战棋战场（再叠单挑、计略）  
7. 外交 + 胜负  
8. 存档接完整 `GameState`

## 14. 验收

玩过安卓《三國志２》的人应能一眼认出：

> 管城、派将、进格子战场、能单挑，最后统一。
