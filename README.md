# 三国志 · 天下争锋

原创三国志类回合制策略游戏（Cocos Creator 3.8 + 官方逻辑还原）。

## 官方流程（当前实现）

```
主菜单 → 选剧本 → 选势力 → 战略地图 → 选城 → 命令大类 → 结束回合
                              ├ 内政：开发/开垦/治理
                              ├ 军事：征兵/出兵/运输/联合军/一骑讨/伏兵
                              ├ 人才：移动/赏赐/任命/搜索/登用在野武将
                              ├ 计谋：火计/离间/扰乱/伪报/鼓舞
                              └ 外交：同盟/停战/宣战/赠礼
         → AI 回合（含运输/伪报/联合军）→ 月结算 → 下一回合
```

## 剧本

| 剧本 | 说明 |
|------|------|
| 三足鼎立 | 200年标准开局，24武将 |
| 赤壁争锋 | 208年前线对峙，在野名将（庞德、徐晃、张郃、太史慈） |

## 运行

```bash
npm test           # 单元测试
npm run flow       # CLI 流程演示
npm run simulate   # 多回合模拟
npm run generate:audio      # 生成 WAV 音效
npm run generate:portraits  # 生成武将立绘 PNG
```

Cocos Creator：打开 `Game` 场景 → 预览；主菜单应显示 `构建 UI-v1.5.0`。Logo `resources/brand/logo.webp`；游戏图标 7 张（`resources/icons/`）可在设置或主菜单切换；背景 13 张 WebP（`resources/backgrounds/`）。同步命令：`npm run sync:backgrounds`、`npm run sync:portraits`。
